# 03 — Open Interpreter

**O que faz:** fornece ferramentas para executar tarefas no computador por meio de sessões controladas.

**Fonte oficial:** https://github.com/openinterpreter/openinterpreter

**Ligação no Ideon:** pode ser conectado pelo cliente MCP existente em `ferramentas-verso.js`, após instalar e configurar o servidor MCP do Interpreter. Configure apenas ferramentas específicas, revise seus argumentos e autorize a ação pelo Ideon.

O serviço não vem instalado nem iniciado pelo app. Limites de pastas, rede e comandos precisam ser aplicados também no próprio serviço e no sistema operacional; a autorização da interface, sozinha, não cria isolamento.
