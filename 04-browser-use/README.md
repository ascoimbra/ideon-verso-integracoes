# 04 — Browser Use

**O que faz:** automatiza tarefas em um navegador por meio das ferramentas oferecidas pelo projeto.

**Fonte oficial:** https://github.com/browser-use/browser-use/tree/main/browser_use

**Ligação no Ideon:** pode ser conectado como servidor MCP ao cliente existente em `ferramentas-verso.js`. Instale e revise o servidor separadamente; descubra as ferramentas, permita somente as necessárias e autorize cada envio pelo Ideon.

Não é um navegador autônomo já ativo no pacote. A configuração do serviço precisa limitar o perfil do navegador, arquivos e rede. Evite sessões pessoais e dados sensíveis.
