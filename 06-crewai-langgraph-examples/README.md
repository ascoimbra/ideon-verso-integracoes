# 06 — Exemplo CrewAI + LangGraph

**O que é:** um exemplo de referência que demonstra integração entre CrewAI e LangGraph.

**Fonte oficial:** https://github.com/crewAIInc/crewAI-examples/tree/main/integrations/CrewAI-LangGraph

**Situação no Ideon:** não está instalado nem é usado pelo app. O Ideon já usa LangGraph JavaScript para orquestrar seu fluxo local. Adicionar CrewAI exigiria um runtime Python/serviço extra e uma decisão de arquitetura; esta pasta registra a referência, sem duplicar o orquestrador.
